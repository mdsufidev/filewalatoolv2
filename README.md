# FileWalaTool v2

FileWalaTool v2 is a Next.js App Router project for browser-based image, PDF, conversion, and document tools.

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to view the site.

## Project Structure

- `src/app/page.tsx` renders the FileWalaTool homepage.
- `src/app/layout.tsx` provides the shared header, footer, chat widget, and global styles.
- `src/components/home` contains the homepage sections.
- `src/components/tools` contains tool UIs.
- `public` contains static images and app icons.

## Build

```bash
npm run build
```

## Vercel
