# Search Indexing Checklist

Use the production domain for all checks: `https://www.filewalatool.com`.

## Google Search Console

- Verify ownership for `https://www.filewalatool.com`.
- Submit `https://www.filewalatool.com/sitemap.xml`.
- Inspect the homepage and priority URLs:
  - `/tools`
  - `/image-resizer`
  - `/compress-image`
  - `/crop-image`
  - `/merge-pdf`
  - `/pan-photo-resize`
  - `/signature-resize`
  - `/passport-photo`
  - `/resume-builder`
  - `/about`
  - `/contact`
- Check canonical selection for redirect aliases such as `/contact-us`, `/convert`, `/image-to-pdf`, `/pdf-to-jpg`, `/pdf-to-word`, and `/document-scanner`.
- Monitor Core Web Vitals and mobile usability after deployment.
- Review crawl and indexing coverage for excluded admin/API routes.

## Bing Webmaster Tools

- Verify ownership for `https://www.filewalatool.com`.
- Submit `https://www.filewalatool.com/sitemap.xml`.
- Inspect the homepage and major tool URLs.
- Monitor crawl errors, canonical warnings, and index coverage.

## Ongoing Review

- Check that new public tools are added to the sitemap and internal links.
- Keep titles and descriptions unique for each indexable page.
- Verify requirement-based pages when portals change their upload instructions.
- Do not add fake reviews, fake ratings, hidden keyword blocks, or near-duplicate landing pages.
